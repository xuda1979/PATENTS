\noindent\textbf{发明名称：}一种面向6G网络切片的超低时延抗量子自适应握手方法、系统、设备及存储介质

\vspace{1em}

\textbf{权利要求1.} 一种面向6G网络切片的超低时延抗量子自适应握手方法，其特征在于，包括：

\begin{enumerate}[label=\arabic*., leftmargin=2em]
    \item 接收终端发送的握手请求消息，所述握手请求消息至少携带切片标识、终端能力信息以及终端支持的后量子密码算法集合；
    \item 根据所述切片标识对应的切片握手画像，并结合所述终端能力信息和当前链路状态信息，选择与目标切片对应的握手计划，所述握手计划至少包括基础后量子密钥协商参数、增强密钥材料参数、增强密钥材料的分片参数以及增强阶段时限参数；
    \item 按照所述握手计划执行基础后量子密钥协商，获得基础份额，并基于所述基础份额导出基础会话密钥；
    \item 在所述目标切片允许早期业务的情况下，基于所述基础份额、握手转录文本摘要、所述切片标识和所述握手计划导出早期业务密钥，以用于承载预先限定范围内的早期业务；
    \item 生成增强密钥材料，并按照所述分片参数将所述增强密钥材料编码为总数为 $n$ 的多个增强片段，使得至少接收到达到阈值 $t$ 的有效增强片段时能够恢复所述增强密钥材料；
    \item 在所述增强阶段时限内发送或接收所述增强片段，并在达到所述阈值 $t$ 时恢复所述增强密钥材料；
    \item 基于所述基础份额、所述增强密钥材料、所述握手转录文本摘要、所述切片标识和所述握手计划导出最终会话密钥，并将业务承载从所述基础会话密钥或所述早期业务密钥迁移至所述最终会话密钥；
    \item 将所述切片标识、握手计划标识、算法包摘要、分片参数和增强阶段时限参数绑定到所述握手转录文本中，以实现抗降级和抗跨切片重放保护。
\end{enumerate}

\vspace{0.5cm}

\textbf{权利要求2.} 根据权利要求1所述的方法，其特征在于，所述切片握手画像至少包括以下一项或多项：切片时延预算、最小安全等级、允许的算法集合、是否允许早期业务、增强片段恢复阈值、增强阶段失效窗口、业务权限级别。

\vspace{0.5cm}

\textbf{权利要求3.} 根据权利要求1所述的方法，其特征在于，所述根据所述切片握手画像，并结合所述终端能力信息和当前链路状态信息，选择握手计划的步骤，包括：
\[
b^\star=\arg\min_{b \in \mathcal{B}} \left(\alpha \hat{T}(b)+\beta \hat{C}(b)+\gamma \hat{B}(b)+\delta \hat{P}_{loss}(b)\right)
\]
其中，$\hat{T}(b)$ 表示预测握手完成时间，$\hat{C}(b)$ 表示计算成本，$\hat{B}(b)$ 表示握手字节开销，$\hat{P}_{loss}(b)$ 表示因链路丢包导致增强阶段超时的风险。

\vspace{0.5cm}

\textbf{权利要求4.} 根据权利要求1所述的方法，其特征在于，所述增强密钥材料的分片参数包括总分片数 $n$ 和恢复阈值 $t$，且在对所述增强密钥材料执行分片之前，还对所述增强密钥材料执行全有或全无变换、秘密共享、纠删编码中的至少一种处理，以降低部分分片泄露时的信息暴露风险。

\vspace{0.5cm}

\textbf{权利要求5.} 根据权利要求1所述的方法，其特征在于，所述早期业务密钥仅用于承载白名单业务，所述白名单业务至少受切片类型、业务优先级和消息类型中的一项或多项限制，且所述白名单业务范围被纳入所述握手转录文本的绑定内容。

\vspace{0.5cm}

\textbf{权利要求6.} 根据权利要求1所述的方法，其特征在于，所述多个增强片段被映射到后续握手报文、首批业务报文、独立控制报文或多路径子流中的至少一种承载路径进行传输。

\vspace{0.5cm}

\textbf{权利要求7.} 根据权利要求6所述的方法，其特征在于，在通过多路径子流传输所述多个增强片段时，还将路径标识、片段顺序摘要或子流标识中的至少一种信息绑定到所述握手转录文本中。

\vspace{0.5cm}

\textbf{权利要求8.} 根据权利要求1所述的方法，其特征在于，所述方法还包括：在所述增强阶段时限内未达到所述阈值 $t$ 时，根据切片策略执行以下至少一种操作：限制业务范围、降低会话权限、发起补强重协商、请求重发增强片段、撤销当前会话。

\vspace{0.5cm}

\textbf{权利要求9.} 根据权利要求1所述的方法，其特征在于，所述基础后量子密钥协商参数包括单一后量子 KEM 参数集、多个后量子 KEM 参数集、椭圆曲线密钥交换与后量子 KEM 的混合参数集中的至少一种。

\vspace{0.5cm}

\textbf{权利要求10.} 根据权利要求1所述的方法，其特征在于，所述方法还包括生成切片绑定恢复票据，所述切片绑定恢复票据至少绑定切片标识、握手画像标识、握手计划标识、终端能力摘要和策略摘要，以用于相同切片中的快速重连。

\vspace{0.5cm}

\textbf{权利要求11.} 一种面向6G网络切片的超低时延抗量子自适应握手系统，其特征在于，包括：

\begin{enumerate}[label=\alph*), leftmargin=2em]
    \item 切片策略控制模块，用于存储不同网络切片对应的切片握手画像；
    \item 握手计划决策模块，用于根据切片标识、终端能力信息和链路状态信息选择握手计划；
    \item 基础份额协商模块，用于执行基础后量子密钥协商并导出基础会话密钥；
    \item 早期业务控制模块，用于在目标切片允许的情况下导出早期业务密钥并限制其业务承载范围；
    \item 增强材料编码模块，用于生成增强密钥材料并将所述增强密钥材料编码为满足阈值恢复条件的多个增强片段；
    \item 增强片段调度模块，用于在增强阶段时限内调度所述多个增强片段的发送、接收、重传或多路径分发；
    \item 增强材料恢复模块，用于在接收到达到阈值的有效增强片段时恢复增强密钥材料；
    \item 最终密钥导出模块，用于基于基础份额和增强密钥材料导出最终会话密钥；
    \item 转录绑定保护模块，用于将切片标识、握手计划标识、算法包摘要、分片参数和增强阶段时限参数绑定到握手转录文本中。
\end{enumerate}

\vspace{0.5cm}

\textbf{权利要求12.} 根据权利要求11所述的系统，其特征在于，所述握手计划决策模块被配置为针对不同切片分别选择不同的恢复阈值、不同的增强阶段时限或不同的早期业务放行范围，以适配超可靠低时延通信切片、增强移动宽带切片和大规模机器类通信切片中的至少一种。

\vspace{0.5cm}

\textbf{权利要求13.} 根据权利要求11所述的系统，其特征在于，所述增强材料编码模块被配置为采用秘密共享、纠删编码或全有或全无变换与纠删编码相结合的方式，对所述增强密钥材料进行处理。

\vspace{0.5cm}

\textbf{权利要求14.} 根据权利要求11所述的系统，其特征在于，所述增强片段调度模块被配置为将增强片段映射至控制面消息、数据面消息、隧道报文或多路径子流中的至少一种进行传输。

\vspace{0.5cm}

\textbf{权利要求15.} 一种电子设备，其特征在于，包括处理器和存储器，所述存储器中存储有计算机程序，所述计算机程序在被所述处理器执行时，使得所述电子设备执行权利要求1至10任一项所述的方法。

\vspace{0.5cm}

\textbf{权利要求16.} 一种计算机可读存储介质，其上存储有计算机程序，所述计算机程序在被处理器执行时，使得所述处理器执行权利要求1至10任一项所述的方法。
