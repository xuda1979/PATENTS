## 可复现算例

```bash
python evidence/reference_state_machine.py
```

15 个确定性软件场景的原始轨迹见 [scenario_results.json](evidence/scenario_results.json)。包含正常交接、约束变化、预算变化、未完成波形、输入失配、部署字节变化、过期、重放、相位不兼容、累计预算耗尽、回滚、一票多用、首包前状态变化和重启历史未知。

这些是归一化资源下的顺序状态机算例。没有患者数据、人体刺激、硬件测试、LLM 调用或模型训练；没有测量并发原子性、密码认证或掉电持久化。因此不将其表述为临床效果、硬件安全认证或实时性能优势。
