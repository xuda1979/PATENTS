# 备用权利要求书
# 一种面向存储带宽受限 Transformer 前馈网络执行的分块临时权重描述子生成与执行系统及方法

---

## 说明

本套备用权利要求用于在正式检索或审查过程中出现更近动态权重生成、Hypernetwork、低秩压缩或片上权重执行现有技术时，作为较窄但更稳的授权备选方案。

本套备用权利要求主要收敛到 Transformer 前馈网络块的前向执行路径，用于主案统一覆盖“推理 + 训练”时的保授权梯度；训练路径仍以主案说明书和主案权利要求中的反向重算与通信门控特征为主。

本套权利要求相较主案主动上提了以下限制：

1. 目标层限定为 Transformer 前馈网络块；
2. 明确上投影、门控投影和下投影场景；
3. 强调分块生成、分块消费、分块释放次序；
4. 强调分块对象在生命周期结束后立即释放或覆写；
5. 强调单个融合内核 或等效紧耦合执行路径；
6. 强调对应完整稠密矩阵不在外部存储器中物化。

---

## 独立权利要求

### 权利要求1

一种用于 Transformer 前馈网络块执行的神经网络执行系统，其特征在于，包括：

一加速器，所述加速器包括矩阵计算单元、片上存储器以及外部存储器；

一条件模块，用于在当前前向执行步骤中获取条件信号，所述条件信号至少包括当前 token 的特征表示以及目标 Transformer 层的层标识；

一元生成器，用于根据所述条件信号分别为所述前馈网络块的上投影、门控投影和下投影生成权重描述子块，其中，所述权重描述子块包括低秩因子块或者用于重构低秩因子的基系数块；

一融合执行引擎，其被配置为在单个融合内核 或等效紧耦合执行路径中执行以下操作：

1. 将当前权重描述子块写入所述片上存储器；
2. 利用矩阵乘积结合分解或者等效因子分块消费路径对所述当前权重描述子块执行部分线性变换计算；
3. 对部分输出进行累积；
4. 在当前权重描述子块对应的部分输出累积完成后，释放、覆写或清零当前权重描述子块，并在承载该权重描述子块的片上缓冲区被重用前完成所述释放、覆写或清零；

其中，与所述权重描述子块对应的完整稠密权重矩阵在前向执行过程中不存储于所述外部存储器中；以及

一存储生命周期控制器，用于阻止所述权重描述子块在前向执行过程中从所述片上存储器回写至所述外部存储器。

### 权利要求2

一种用于 Transformer 前馈网络块执行的神经网络执行方法，其特征在于，包括：

S1、接收当前前向执行步骤的激活张量；

S2、根据所述激活张量得到当前 token 的特征表示，并结合目标 Transformer 层的层标识形成条件信号；

S3、由元生成器分别为所述前馈网络块的上投影、门控投影和下投影生成当前权重描述子块；

S4、仅将所述当前权重描述子块写入片上存储器，并通过矩阵乘积结合分解或者等效因子分块消费路径执行部分输出计算；

S5、对所述部分输出进行累积；

S6、在所述当前权重描述子块对应的部分输出累积完成后，对所述当前权重描述子块执行释放、覆写或清零，并在承载该权重描述子块的片上缓冲区被重用前完成所述释放、覆写或清零；以及

S7、在整个前向执行过程中，不将与所述权重描述子块对应的完整稠密权重矩阵存储于外部存储器，也不将所述权重描述子块作为持久模型权重回写至外部存储器。

### 权利要求3

一种非暂态计算机可读存储介质，其上存储有程序指令，所述程序指令在由加速器的一个或多个处理器执行时，使所述一个或多个处理器执行如权利要求2所述的方法。

## 从属权利要求

**权利要求4** 根据权利要求1所述的神经网络执行系统，其特征在于，所述权重描述子块包括第一低秩因子块 `U` 和第二低秩因子块 `V`，其秩 `r` 满足 `r < min(d_in, d_out)`。

**权利要求5** 根据权利要求1所述的神经网络执行系统，其特征在于，所述融合执行引擎在执行上投影、门控投影和下投影时分别执行：
`A = phi((XU_up)V_up)`，
`G = psi((XU_gate)V_gate)`，以及
`Y = ((A .* G)U_down)V_down`。

**权利要求6** 根据权利要求1所述的神经网络执行系统，其特征在于，所述元生成器在多个 Transformer 层之间共享，并通过层嵌入区分不同层的生成输出。

**权利要求7** 根据权利要求1所述的神经网络执行系统，其特征在于，所述元生成器输出学习基库的系数，所述融合执行引擎在片上存储器中根据所述系数重构低秩因子块。

**权利要求8** 根据权利要求1所述的神经网络执行系统，其特征在于，所述片上存储器包括寄存器、共享内存、SRAM、缓存或者其组合。

**权利要求9** 根据权利要求1所述的神经网络执行系统，其特征在于，所述条件信号还包括以下至少之一：序列位置嵌入、路由摘要、任务标识、领域标识、批统计量或者硬件执行配置文件。

**权利要求10** 根据权利要求1所述的神经网络执行系统，其特征在于，所述权重描述子块按块顺序被生成、消费和释放，并且每个后续块的生成以前一块已完成释放、覆写或清零为前提。

**权利要求11** 根据权利要求1所述的神经网络执行系统，其特征在于，所述存储生命周期控制器被配置为在对应输出累积完成后对当前权重描述子块执行清零。

**权利要求12** 根据权利要求1所述的神经网络执行系统，其特征在于，所述秩 `r` 根据以下至少之一自适应选择：token 复杂度、层深度、时延目标、可用带宽或者矩阵计算单元占用率。

**权利要求13** 根据权利要求1所述的神经网络执行系统，其特征在于，还包括一调度器，用于按层在动态生成权重路径与静态存储权重路径之间切换。

**权利要求14** 根据权利要求2所述的方法，其特征在于，所述方法全部在单个融合的加速器内核、微代码路径或者等效紧耦合执行路径中执行。

**权利要求15** 根据权利要求2所述的方法，其特征在于，将具有相似条件信号的多个 token 分组，并在有界时间窗口内于所述分组 token 之间复用至少部分权重描述子块，同时保持所述权重描述子块为非持久形式。

**权利要求16** 根据权利要求1所述的神经网络执行系统，其特征在于，还包括一训练流水线，所述训练流水线被配置为从预训练稠密模型初始化，将至少一个前馈网络块的稠密投影替换为所述元生成器和所述融合执行引擎，并利用继续训练或知识蒸馏优化替换后的模型。

## 使用建议

1. 若主案在“动态生成权重”或“片上执行”层面遇到更近对比文献，可直接切换至本套备用权利要求。
2. 本套权利要求更适合在中国审查阶段作为保授权方案使用。
3. 如需进一步收窄，可将权利要求10或权利要求11中的特征上提至权利要求1。
