# 权利要求书
# 一种面向存储带宽受限神经网络推理的即时临时元权重生成系统及方法

---

## 独立权利要求

### 权利要求1

一种神经网络推理系统，其特征在于，包括：

一加速器，所述加速器包括矩阵计算单元、片上存储区域以及外部存储区域；

一条件模块，用于在当前推理步骤中获取条件信号，所述条件信号至少包括与 token 相关的特征表示和对应目标神经网络层的层标识；

一元生成器，用于根据所述条件信号生成至少一个目标神经网络层线性变换的权重描述子 tile，其中，所述权重描述子 tile 包括低秩因子、用于重构低秩因子的基系数，或其组合；

一融合执行引擎，用于：

1. 将生成的权重描述子 tile 置于所述片上存储区域中；
2. 通过包括 `Y = (XU)V` 的矩阵乘积结合分解来计算所述线性变换；
3. 在所述生成的权重描述子 tile 保持于所述片上存储区域中的同时累积输出 tile；以及
4. 在生成下一个权重描述子 tile 之前释放或覆写当前权重描述子 tile；

其中，所述融合执行引擎在不将与所述权重描述子对应的完整稠密权重矩阵存储到所述外部存储区域中的情况下完成所述线性变换；以及

一存储生命周期控制器，用于在推理过程中阻止所述生成的权重描述子 tile 从所述片上存储区域回写至所述外部存储区域。

### 权利要求2

一种在包括矩阵计算单元、片上存储和外部存储的加速器上执行的存储高效型神经网络推理方法，其特征在于，包括：

S1、接收当前推理步骤的激活张量；

S2、利用从所述激活张量得到的 token 特征表示和层标识形成条件信号；

S3、由元生成器为至少一个神经网络层投影生成权重描述子 tile；

S4、针对每一个生成的权重描述子 tile，仅将该权重描述子 tile 存储于片上存储中，并通过矩阵乘积结合分解计算部分输出，在计算过程中不在外部存储中物化对应的完整稠密权重矩阵；

S5、对所述部分输出进行累积以得到所述投影的输出张量；以及

S6、在生成下一个权重描述子 tile 之前，于所述片上存储中释放或覆写当前权重描述子 tile，而不将所述权重描述子 tile 作为持久模型权重存储于外部存储中。

### 权利要求18

一种非暂态计算机可读存储介质，其上存储有程序指令，所述程序指令在由加速器的一个或多个处理器执行时，使所述一个或多个处理器执行如权利要求2所述的方法。

## 从属权利要求

### 从属于权利要求1的权利要求

**权利要求3** 根据权利要求1所述的神经网络推理系统，其特征在于，所述目标神经网络层为 Transformer 模型中的前馈网络块。

**权利要求4** 根据权利要求3所述的神经网络推理系统，其特征在于，所述融合执行引擎被配置为针对所述前馈网络块的上投影、门控投影和下投影分别生成对应的权重描述子 tile。

**权利要求5** 根据权利要求1所述的神经网络推理系统，其特征在于，所述条件信号还包括以下至少之一：序列位置嵌入、路由摘要、领域标识、任务标识、批统计量或硬件执行配置文件。

**权利要求6** 根据权利要求1所述的神经网络推理系统，其特征在于，所述元生成器在多个 Transformer 层之间共享，并通过层嵌入区分不同层的生成输出。

**权利要求7** 根据权利要求1所述的神经网络推理系统，其特征在于，所述权重描述子 tile 包括第一低秩因子 tile `U` 和第二低秩因子 tile `V`，其秩 `r` 满足 `r < min(d_in, d_out)`，其中 `d_in x d_out` 为目标投影的维度。

**权利要求8** 根据权利要求1所述的神经网络推理系统，其特征在于，所述元生成器输出学习基库的系数，所述融合执行引擎在所述片上存储区域内根据所述系数重构所述低秩因子。

**权利要求9** 根据权利要求1所述的神经网络推理系统，其特征在于，所述融合执行引擎由持久化加速器内核 实现，以在单次 内核启动中完成所述权重描述子 tile 的生成、消耗、累积和释放。

**权利要求10** 根据权利要求1所述的神经网络推理系统，其特征在于，所述片上存储区域包括寄存器、共享内存、SRAM、缓存或其组合。

**权利要求11** 根据权利要求1所述的神经网络推理系统，其特征在于，所述存储生命周期控制器被配置为在对应输出 tile 累积后对所述权重描述子 tile 进行清零或覆写。

**权利要求12** 根据权利要求1所述的神经网络推理系统，其特征在于，所述秩 `r` 根据以下至少之一自适应选择：token 复杂度、层深度、时延目标、可用带宽或矩阵计算单元占用率。

**权利要求13** 根据权利要求1所述的神经网络推理系统，其特征在于，还包括一调度器，所述调度器用于按层、按 token 或按批次 在生成权重描述子与静态存储权重之间进行切换。

### 从属于权利要求2的权利要求

**权利要求14** 根据权利要求2所述的方法，其特征在于，步骤 S3 包括生成第一低秩因子 tile `U` 和第二低秩因子 tile `V`，步骤 S4 包括执行 `Y = (XU)V`。

**权利要求15** 根据权利要求2所述的方法，其特征在于，所述神经网络层为门控前馈网络块，步骤 S4 包括：
`A = phi((XU_up)V_up)`，
`G = psi((XU_gate)V_gate)`，以及
`Y = ((A .* G)U_down)V_down`。

**权利要求16** 根据权利要求2所述的方法，其特征在于，将具有相似条件信号的多个 token 分组，并在有界时间窗口内于所述分组 token 之间复用至少部分生成的权重描述子，同时保持所述权重描述子为非持久形式。

**权利要求17** 根据权利要求2所述的方法，其特征在于，所述方法全部在单个融合的 Triton、CUDA、ROCm、HIP 或等效加速器内核 中执行。

### 训练与迁移权利要求

**权利要求19** 根据权利要求1所述的神经网络推理系统，其特征在于，还包括一训练流水线，所述训练流水线被配置为从预训练稠密模型初始化，将至少一个存储的稠密投影替换为所述元生成器和所述融合执行引擎，冻结原模型参数的第一子集，并利用持续训练或知识蒸馏优化剩余参数。

**权利要求20** 根据权利要求19所述的神经网络推理系统，其特征在于，所述训练流水线最小化的损失包括以下至少之一：token 级交叉熵、隐藏状态匹配、注意力图匹配、相对于教师模型的 KL 散度或带宽感知正则项。
