# 专利代理人封面说明
# MWG-EW 申请包说明

---

## 一、目的

本说明用于帮助专利代理人快速理解本案的技术核心、当前撰写策略、主案与备用案的关系，以及后续需要重点处理的问题。

本案名称建议为：

**一种面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法**

---

## 二、先给出的核心指令

请将以下五点作为正式撰写和后续答审的硬约束：

1. 同一申请中同时覆盖推理和训练，不把训练仅写成弱化的“迁移训练”尾注。
2. 权利要求采用三层结构：前向核心防御、推理解码防御、训练与通信防御。
3. 主权项尽量使用内存层级、算术逻辑单元、生命周期控制等物理硬件语言，避免把数学公式写成主权项中心。
4. 主权项避免使用厂商平台术语，具体平台仅放入实施例。
5. 说明书中主动记载 profiler、内存计数器和网络抓包可见的物理可观测特征。

---

## 三、技术核心

本案并非单纯主张“动态生成权重”或“低秩分解”，而是主张以下统一执行闭环：

`运行时条件生成 -> 临时权重描述子分块 -> 片上转换并消费 -> 用后释放 -> 全生命周期不回写外部存储器 -> 可选反向重算 -> 可选通信豁免`

建议代理人在正式撰写和后续答审时始终围绕以下技术边界展开：

1. 加速器内存层级明确区分片上局部存储器与外部存储器；
2. 条件信号至少包括激活特征表示与层标识；
3. 生成对象为临时权重描述子块，而非要求持久保存的完整稠密权重矩阵；
4. 临时对象仅在片上局部存储器中转换、驻留并被消费；
5. 在当前块计算完成后释放、覆写或清零当前块，并在对应片上缓冲区被重用前完成该流程；
6. 在全生命周期内不将对应目标权重分块的完整物理形态写回外部存储器；
7. 可选地，将节省的外部存储容量动态分配给键值缓存；
8. 可选地，在训练反向传播中再次片上生成对应块，并使局部梯度块不进入优化器状态缓存且不参与跨节点同步。

## 四、当前撰写策略

### 1. 主案

主案用于争取较好的保护范围，文件为：

- `claims_CN_final.md`
- `patent_spec_CN_final.md`
- `abstract_CN_final.md`

主案特点：

1. 已将前向执行与反向训练统一进同一底层架构；
2. 主权项采用“算术逻辑单元 + 片上局部存储器 + 生命周期控制”的物理写法；
3. 推理侧的 KV Cache 与双缓冲、训练侧的反向重算与通信门控均保留为强从属梯度。

### 2. 备用案

备用案用于在正式检索或审查中遇到更近文献时快速切换，文件为：

- `claims_CN_backup.md`

备用案特点：

1. 可进一步限定 Transformer 前馈网络块；
2. 可上提上投影、门控投影和下投影；
3. 可上提单个融合 kernel / 等效紧耦合执行路径；
4. 可上提“当前块完成后释放，并在对应片上缓冲区重用前完成该流程”的次序关系；
5. 更适合作为保授权路径。

## 五、代理人建议重点关注的问题

### 1. 权利要求风格

请优先保持以下术语稳定：

1. `片上局部存储器`
2. `外部存储器`
3. `临时权重描述子块`
4. `临时目标权重分块`
5. `第一算术逻辑单元`
6. `第二算术逻辑单元`
7. `不回写`
8. `节点间高带宽通信总线`

不建议在正式稿中将上述术语频繁改写成多个替代词，以免削弱说明书与权利要求的一致性。

### 2. 审查答复口径

若审查员引用以下现有技术方向，请按如下思路处理：

1. 若引用 Hypernetwork/动态权重生成文献：
   重点强调本案不是宽泛的“生成权重”，而是“在片上局部存储器中按块生成、消费、释放且不回写”的执行闭环。
2. 若引用低秩分解/LoRA 文献：
   重点强调本案不主张低秩数学本身，而主张低秩描述子与运行时生命周期控制的结合。
3. 若引用片上常驻权重/本地存储加速器文献：
   重点强调本案对象是“运行时即时生成并即时销毁”的临时对象，而不是预先下发的静态权重。
4. 若引用训练通信优化文献：
   重点强调本案并非单纯压缩梯度，而是对与临时权重描述子块对应的局部梯度块实施去优化器状态、去同步的路径截断。

### 3. 平台无关写法

请在主权项中避免写入厂商或平台专有术语。建议映射如下：

1. `HBM / DDR / 显存` -> `外部存储器`
2. `UB / L0 / Shared Memory / SRAM` -> `片上局部存储器`
3. `Vector / CUDA Core / SIMD` -> `第一算术逻辑单元`
4. `Tensor Core / Cube / Systolic Array` -> `第二算术逻辑单元`
5. `HCCS / NVLink / InfiniBand / RoCE` -> `节点间高带宽通信总线`

### 4. 法域适配

当前文本主要针对中国审查思路组织，但其结构也适合作为 PCT / US / EP 的基线。若后续进行多法域申请，建议保留：

1. 系统 claim；
2. 方法 claim；
3. 存储介质 claim；
4. 推理解码与训练通信特征作为修改梯度或分案储备。
