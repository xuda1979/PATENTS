# 权利要求书定稿建议
# 一种面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法

---

## 独立权利要求

### 权利要求1

一种神经网络执行系统，其特征在于，包括：

一加速器，所述加速器包括第一算术逻辑单元、第二算术逻辑单元、片上局部存储器以及外部存储器；

一条件模块，用于在当前前向执行步骤或者反向传播步骤中获取条件信号，所述条件信号至少包括与当前激活块对应的特征表示以及目标神经网络层的层标识；

一元生成器，用于根据所述条件信号生成所述目标神经网络层至少一个线性变换对应的临时权重描述子块，其中，所述临时权重描述子块包括低秩因子块、用于重构低秩因子的基系数块、用于形成目标权重分块的控制参数块或者其组合；

一融合执行引擎，用于：

1. 将当前激活块和所述临时权重描述子块写入所述片上局部存储器；
2. 控制所述第一算术逻辑单元在所述片上局部存储器中将所述临时权重描述子块转换为对应的临时目标权重分块或者等效因子分块；
3. 控制所述第二算术逻辑单元基于所述当前激活块以及所述临时目标权重分块或者等效因子分块执行矩阵乘加运算，以生成并累积当前输出块或者当前梯度块；以及
4. 在所述当前输出块或者当前梯度块计算完成后释放、覆写或者清零当前临时权重描述子块以及所述临时目标权重分块或者等效因子分块，并在对应片上缓冲区被重用前完成所述释放、覆写或者清零；

其中，在所述当前临时权重描述子块及其对应的临时目标权重分块的全生命周期内，不将其完整物理形态写回至所述外部存储器；以及

一存储生命周期控制器，用于阻止所述临时权重描述子块及其对应的临时目标权重分块从所述片上局部存储器回写至所述外部存储器。

### 权利要求2

一种在包括第一算术逻辑单元、第二算术逻辑单元、片上局部存储器和外部存储器的加速器上执行的神经网络执行方法，其特征在于，包括：

S1、接收当前前向执行步骤或者反向传播步骤中的激活块、中间状态块或者梯度信号，并确定目标神经网络层的层标识；

S2、基于所述激活块、中间状态块或者梯度信号以及所述层标识形成条件信号；

S3、由元生成器根据所述条件信号生成当前线性变换对应的临时权重描述子块；

S4、仅将所述临时权重描述子块写入片上局部存储器，并在所述片上局部存储器中将所述临时权重描述子块转换为临时目标权重分块或者等效因子分块，进而驱动所述第二算术逻辑单元计算当前输出块或者当前梯度块；

S5、在所述当前输出块或者当前梯度块计算完成后，于所述片上局部存储器中释放、覆写或者清零当前临时权重描述子块以及所述临时目标权重分块或者等效因子分块，并在对应片上缓冲区被重用前完成所述释放、覆写或者清零；以及

S6、在所述当前临时权重描述子块及其对应的临时目标权重分块的全生命周期内，阻止将其完整物理形态写回至所述外部存储器。

### 权利要求3

一种非暂态计算机可读存储介质，其上存储有程序指令，所述程序指令在由加速器的一个或多个处理器执行时，使所述一个或多个处理器执行如权利要求2所述的方法。

## 从属权利要求

### 从属于权利要求1的权利要求

**权利要求4** 根据权利要求1所述的神经网络执行系统，其特征在于，所述目标神经网络层为 Transformer 模型中的前馈网络块。

**权利要求5** 根据权利要求4所述的神经网络执行系统，其特征在于，所述融合执行引擎被配置为分别针对所述前馈网络块的上投影、门控投影和下投影生成对应的临时权重描述子块。

**权利要求6** 根据权利要求1所述的神经网络执行系统，其特征在于，所述条件信号还包括以下至少之一：序列位置嵌入、路由摘要、领域标识、任务标识、批统计量、序列长度信息或者硬件执行配置文件。

**权利要求7** 根据权利要求1所述的神经网络执行系统，其特征在于，所述元生成器在多个 Transformer 层之间共享，并通过层嵌入区分不同层的生成输出。

**权利要求8** 根据权利要求1所述的神经网络执行系统，其特征在于，所述临时权重描述子块包括第一低秩因子块和第二低秩因子块，或者包括用于在片上局部存储器中重构所述第一低秩因子块和所述第二低秩因子块的基系数块。

**权利要求9** 根据权利要求8所述的神经网络执行系统，其特征在于，所述元生成器输出学习基库的系数，所述融合执行引擎在所述片上局部存储器中根据所述系数重构所述第一低秩因子块和所述第二低秩因子块。

**权利要求10** 根据权利要求1所述的神经网络执行系统，其特征在于，所述融合执行引擎由持久化加速器 kernel 或者等效紧耦合微代码路径实现，以在单次启动中完成所述临时权重描述子块的生成、消费、累积和释放。

**权利要求11** 根据权利要求1所述的神经网络执行系统，其特征在于，所述片上局部存储器包括寄存器、共享内存、SRAM、缓存或者其组合。

**权利要求12** 根据权利要求1所述的神经网络执行系统，其特征在于，所述存储生命周期控制器被配置为在对应输出块或者梯度块累积完成后对所述临时权重描述子块执行清零或者覆写。

**权利要求13** 根据权利要求8所述的神经网络执行系统，其特征在于，所述第一低秩因子块和第二低秩因子块的秩值或者块大小根据以下至少之一自适应选择：token 复杂度、层深度、时延目标、可用带宽、片上局部存储容量或者矩阵计算单元占用率。

**权利要求14** 根据权利要求1所述的神经网络执行系统，其特征在于，还包括一调度器，所述调度器用于按层、按 token、按 batch 或按训练阶段在生成权重路径与静态存储权重路径之间进行切换。

**权利要求15** 根据权利要求1所述的神经网络执行系统，其特征在于，所述系统用于自回归解码推理，并且节省的外部存储空间被动态分配给键值缓存或者其他上下文状态缓存。

**权利要求16** 根据权利要求15所述的神经网络执行系统，其特征在于，所述片上局部存储器包括至少两个交替使用的缓冲区，其中在所述第二算术逻辑单元消费当前临时权重描述子块时，所述元生成器和所述第一算术逻辑单元于另一缓冲区中生成下一临时权重描述子块，以实现生成过程与矩阵乘加过程的时间重叠。

**权利要求17** 根据权利要求1所述的神经网络执行系统，其特征在于，将具有相似条件信号的多个 token 分组，并在有界时间窗口内于所述分组 token 之间复用至少部分临时权重描述子块，同时保持所述临时权重描述子块为非持久形式。

### 从属于权利要求2的权利要求

**权利要求18** 根据权利要求2所述的方法，其特征在于，步骤 S3 生成第一低秩因子块和第二低秩因子块，或者生成用于在片上局部存储器中重构所述第一低秩因子块和所述第二低秩因子块的基系数块。

**权利要求19** 根据权利要求2所述的方法，其特征在于，所述方法全部在单个融合的加速器 kernel、微代码路径或者等效紧耦合执行路径中执行。

### 训练与分布式执行权利要求

**权利要求20** 根据权利要求1所述的神经网络执行系统，其特征在于，还包括一反向重算模块，所述反向重算模块被配置为在反向传播过程中响应对目标权重分块或者局部梯度计算操作数的读取请求，再次在所述片上局部存储器中生成对应的临时权重描述子块，并驱动所述第二算术逻辑单元完成对应局部梯度块的计算，而不在所述外部存储器中实体化对应的完整稠密权重矩阵。

**权利要求21** 根据权利要求20所述的神经网络执行系统，其特征在于，还包括一优化器与通信门控控制器，所述优化器与通信门控控制器用于阻止与所述临时权重描述子块对应的局部梯度块进入全局优化器状态缓存，并使所述局部梯度块豁免参与多个计算节点之间经由节点间高带宽通信总线执行的梯度同步，而仅对所述元生成器参数、基库参数或者其他压缩参数子集进行跨节点同步。

**权利要求22** 根据权利要求20或21所述的神经网络执行系统，其特征在于，所述系统被配置为从预训练稠密模型初始化，将至少一个存储的稠密投影替换为所述元生成器和所述融合执行引擎，冻结原模型参数的第一子集，并利用继续训练或知识蒸馏优化剩余参数。

## 定稿说明

1. 本版将主权项从“推理”扩展为“执行”，用同一底层架构覆盖前向推理、解码场景和反向训练场景。
2. 独立权利要求采用“片上局部存储器 / 外部存储器 / 算术逻辑单元 / 生命周期控制”的物理硬件写法，弱化数学公式在主权项中的中心地位。
3. 推理侧的 KV Cache 与双缓冲、训练侧的反向重算与通信豁免均已作为强从属特征写入，便于后续在中国、PCT 或美国申请中按审查压力上提。
