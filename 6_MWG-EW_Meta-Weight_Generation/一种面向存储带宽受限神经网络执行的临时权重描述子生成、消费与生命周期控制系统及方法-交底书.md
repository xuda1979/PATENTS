## 二、技术交底摘要

本发明提出一种面向存储带宽受限神经网络执行的底层架构方案。对于 Transformer 等模型中的目标线性变换，系统不再依赖将完整稠密权重矩阵以持久形式存储于外部存储器并在前向或反向过程中反复读取，而是根据至少包括激活特征表示和层标识的条件信号，在执行时由元生成器实时生成临时权重描述子块，并在片上局部存储器中将其转换为临时目标权重分块或者等效因子分块，由算术逻辑单元立即消费。所述临时对象在当前块计算完成后即进入释放、覆写或清零流程，并在对应片上缓冲区被重用前完成该流程，且在全生命周期内不得以完整物理形态写回外部存储器。

该方案统一覆盖三类场景：其一，前向推理/解码中降低外部存储流量并可把节省的空间动态分配给键值缓存；其二，训练反向传播中再次在片上局部存储器里重算对应块，以完成局部梯度计算；其三，分布式训练中阻止与临时权重描述子块对应的局部梯度块进入全局优化器状态缓存并豁免参与跨节点同步，仅同步元生成器或其他压缩参数子集。

## 四、背景技术

### 1. 现有技术背景

在大语言模型和其他 Transformer 模型中，大量参数集中于前馈网络块以及其他目标线性变换层。推理时，这些矩阵通常以静态稠密权重的形式保存在外部存储器中，并在每层、每 token 的计算中被反复读取到片上资源。训练时，除了前向读取外，还需要在反向传播中再次使用这些权重完成梯度计算，并为对应梯度维护优化器状态以及跨节点同步通信。

随着矩阵计算单元吞吐不断提升，而高带宽显存、片外存储和节点间通信带宽的提升相对有限，系统越来越容易受到权重搬运、优化器状态访问和 All-Reduce 通信的限制，形成外部存储与网络双重瓶颈。

### 2. 已知方案

现有技术通常通过以下方式改进：

1. 量化，降低单位权重位宽；
2. 剪枝或静态低秩压缩，减少持久参数规模；
3. LoRA 或其他参数高效微调方法，降低训练参数规模；
4. Mixture-of-Experts，通过稀疏激活减少有效计算量；
5. Hypernetwork 或动态滤波器方法，根据输入生成权重或滤波核；
6. IO-aware kernel 或 SRAM 常驻加速器设计，降低中间结果与权重的外存访问；
7. ZeRO、分片优化器或其他训练系统，用于压缩优化器状态和同步流量。

### 3. 现有技术存在的问题

上述方案各自有作用，但仍存在以下不足：

1. 量化和静态低秩压缩仍默认权重为持久参数，执行时仍需读取；
2. Hypernetwork 类方法通常强调“生成权重”这一概念，但未突出片上局部存储器中的分块生命周期控制；
3. SRAM 常驻或 IO-aware kernel 类方案通常默认权重事先存在，并未解决运行时临时生成与即时销毁的问题；
4. 分布式训练优化更多聚焦梯度压缩或状态分片，未把“运行时临时生成的权重分块不进入优化器状态也不同步”作为统一执行约束；
5. 现有技术普遍未将以下组合完整落地为系统执行闭环：

`条件生成 -> 临时权重描述子分块 -> 片上转换/消费 -> 用后释放 -> 不回写外部存储器 -> 可选反向重算 -> 可选通信豁免`

## 五、发明目的

本发明的目的在于提供一种神经网络执行系统和方法，用于在不依赖外部存储器反复读取完整稠密投影矩阵的情况下，完成目标神经网络层的前向计算和反向梯度计算，从而：

1. 降低目标投影的外部存储流量；
2. 提高矩阵计算单元利用率；
3. 将部分推理路径从“带宽受限”转变为“片上计算受限”；
4. 在解码场景中为键值缓存释放更多外部存储空间；
5. 在训练场景中减少优化器状态访问和跨节点同步负担；
6. 形成可通过 profiler 和网络抓包工具观测的外部物理特征。

## 六、发明核心方案

### 1. 核心思路

本发明不再将目标线性变换的完整稠密权重矩阵作为必须长期存在于外部存储器中的操作数，而是通过元生成器在执行时根据条件信号生成临时权重描述子块，并由融合执行引擎在片上局部存储器中直接将其转换为临时目标权重分块或者等效因子分块后立即消费。

### 2. 物理控制闭环

本发明的核心闭环为：

`条件输入 -> 生成临时权重描述子块 -> 写入片上局部存储器 -> 片上转换并消费 -> 累积结果 -> 释放/覆写 -> 全生命周期不回写外部存储器`

当处于训练场景时，所述闭环进一步扩展为：

`前向闭环 -> 反向读取请求 -> 片上再次生成对应块 -> 计算局部梯度 -> 截断优化器状态/同步 -> 释放`

### 3. 关键点

1. 条件信号至少包括激活特征表示和层标识；
2. 生成对象为临时权重描述子块，而不是持久保存的完整稠密矩阵；
3. 临时对象只允许在片上局部存储器中形成并被消费；
4. 在当前块计算完成后即进入释放、覆写或清零流程，并在对应片上缓冲区被重用前完成该流程；
5. 在全生命周期内，不将对应目标权重分块的完整物理形态写回外部存储器；
6. 可选地，在解码场景中将节省的外部存储容量重分配给键值缓存；
7. 可选地，在训练场景中对局部梯度块实施优化器状态和跨节点同步门控。

## 七、术语定义与平台泛化

为避免歧义，建议代理人在说明书中使用以下统一术语：

1. **片上局部存储器**：包括寄存器、共享内存、SRAM、缓存或其组合；
2. **外部存储器**：包括高带宽显存、片外 DRAM、主机内存、持久存储或其组合；
3. **临时权重描述子块**：指低秩因子块、用于重构低秩因子的基系数块、用于形成目标权重分块的控制参数块或其组合；
4. **临时目标权重分块**：指根据临时权重描述子块在片上局部存储器中形成并立即用于当前块计算的权重分块；
5. **第一算术逻辑单元**：执行标量、向量、非线性、系数重构或地址控制的处理单元；
6. **第二算术逻辑单元**：执行高密度矩阵乘加、张量乘加或等效乘累加的处理单元；
7. **节点间高带宽通信总线**：包括 NVLink、HCCS、InfiniBand、RoCE 或等效互连；
8. **不回写**：指在全生命周期内不将临时权重描述子块及其对应的临时目标权重分块以完整物理形态写入外部存储器。

建议在正式权利要求中使用泛化后的术语，不要在主权项中写入特定厂商平台术语。实施例中可使用具体平台作为落地例子，但应明确说明其仅为可选实现。建议映射如下：

| 平台相关对象 | 建议保护术语 |
| --- | --- |
| HBM、片外显存、主板 DDR | 外部存储器 |
| UB、L0A、L0B、shared memory、L1 SRAM | 片上局部存储器 |
| Vector、CUDA Core、SIMD Core | 第一算术逻辑单元 |
| Cube、Tensor Core、脉动阵列 | 第二算术逻辑单元 |
| HCCS、NVLink、InfiniBand、RoCE | 节点间高带宽通信总线 |

## 八、系统结构

系统至少包括以下模块：

### 1. 加速器

包括：

1. 第一算术逻辑单元；
2. 第二算术逻辑单元；
3. 片上局部存储器；
4. 外部存储器；
5. 可选的节点间高带宽通信总线接口。

### 2. 条件模块

用于形成条件信号，条件信号至少包括：

1. 当前激活块的特征表示；
2. 目标神经网络层的层标识。

可选还包括：

1. 序列位置嵌入；
2. 序列长度信息；
3. 路由摘要；
4. 任务标识；
5. 领域标识；
6. 批统计量；
7. 硬件执行配置文件。

### 3. 元生成器

用于根据条件信号生成临时权重描述子块。优选情况下，元生成器可在多个 Transformer 层之间共享，并通过层嵌入产生不同层的区分性输出。

### 4. 融合执行引擎

用于：

1. 将生成的临时权重描述子块写入片上局部存储器；
2. 在片上局部存储器中将其转换为临时目标权重分块或者等效因子分块；
3. 驱动第二算术逻辑单元完成当前输出块或者当前梯度块计算；
4. 在下一块生成前释放、覆写或清零当前对象。

### 5. 存储生命周期控制器

用于管理临时权重描述子块和临时目标权重分块的生命周期，并阻止其回写至外部存储器。

### 6. 可选反向重算模块

用于在反向传播时再次在片上局部存储器中生成对应的临时权重描述子块，并完成局部梯度块计算。

### 7. 可选优化器与通信门控控制器

用于阻止与临时权重描述子块对应的局部梯度块进入优化器状态缓存，并豁免其参与跨节点同步。

### 8. 可选解码缓存分配器

用于将节省的外部存储容量动态重分配给键值缓存或其他上下文状态缓存。

### 9. 可选监测模块

用于暴露外部存储读写字节数、矩阵计算单元利用率和节点间同步体积。

## 九、方法流程

### 1. 前向执行流程

前向执行可包括：

1. 接收当前推理步骤的激活块；
2. 形成条件信号；
3. 生成至少一个目标投影对应的临时权重描述子块；
4. 将该临时权重描述子块仅写入片上局部存储器；
5. 在片上局部存储器中转换为临时目标权重分块或者等效因子分块；
6. 驱动第二算术逻辑单元计算当前输出块；
7. 在当前块计算完成后释放、覆写或清零当前对象，并在对应片上缓冲区被重用前完成该流程；
8. 不将其完整物理形态写回外部存储器。

### 2. 解码执行流程

在自回归解码实施方式中，还可包括：

1. 根据权重搬运节省的外部存储容量扩展键值缓存；
2. 使用至少两个片上缓冲区，在一个缓冲区执行当前块计算的同时，在另一缓冲区生成下一块；
3. 通过时间重叠隐藏生成延迟。

### 3. 训练反向流程

训练反向可包括：

1. 接收当前反向传播步骤中的梯度信号；
2. 触发对目标层权重读取请求的拦截；
3. 再次在片上局部存储器中生成对应的临时权重描述子块；
4. 计算局部梯度块、输入梯度块或者参数梯度块；
5. 阻止该局部梯度块进入全局优化器状态缓存；
6. 阻止该局部梯度块参与多节点梯度同步；
7. 仅同步元生成器参数、基库参数或者其他压缩参数子集；
8. 释放当前对象。

## 十、关键实施方式

### 实施方式一：直接生成低秩因子块

元生成器直接输出低秩因子块，并由融合执行引擎在片上局部存储器中立即消费。

### 实施方式二：基库系数重构

元生成器输出基库系数，融合执行引擎在片上局部存储器中重构低秩因子块，然后立即执行计算。

### 实施方式三：Transformer 前馈网络块

目标层为 Transformer 的前馈网络块。对于上投影、门控投影和下投影分别生成临时权重描述子块。

### 实施方式四：分块执行

以块为粒度执行：

1. 生成一个临时权重描述子块；
2. 片上转换并消费；
3. 计算一个当前输出块或者当前梯度块；
4. 累积；
5. 释放当前块；
6. 进入下一块。

### 实施方式五：单 kernel 融合

优选地，在单次持久化 kernel 启动中完成：

1. 条件处理；
2. 临时权重描述子块生成；
3. 片上局部存储写入；
4. 片上转换；
5. 矩阵计算；
6. 结果累积；
7. 生命周期结束处理。

### 实施方式六：自适应秩或块大小

秩值或块大小根据以下至少之一动态调整：

1. token 复杂度；
2. 层深度；
3. 时延目标；
4. 可用带宽；
5. 片上局部存储容量；
6. 矩阵计算单元占用率。

### 实施方式七：分组 token 复用

对于条件信号相近的一组 token，在有界时间窗口内复用至少部分临时权重描述子块，但保持其非持久性和不回写特征。

### 实施方式八：训练反向重算

在反向传播计算梯度时，系统拦截对目标权重分块的读取请求，再次在片上局部存储器中生成对应的临时权重描述子块，并完成局部梯度计算。

### 实施方式九：优化器与同步截断

与临时权重描述子块对应的局部梯度块不进入全局优化器状态缓存，也不参与多节点间的 All-Reduce 或等效同步，仅同步元生成器参数、基库参数或者其他压缩参数子集。

### 实施方式十：从预训练稠密模型迁移

从预训练稠密模型开始：

1. 选择目标投影；
2. 插入元生成器和融合执行路径；
3. 冻结部分原参数；
4. 通过继续训练或知识蒸馏恢复精度。

## 十一、可观测特征

为便于后续取证和侵权侦测，建议在说明书中主动定义以下外部物理可观测特征：

1. 在执行目标层时，外部存储器读写字节数显著低于按完整稠密权重矩阵访存所对应的理论下限；
2. 矩阵计算单元利用率保持在高水平，而等待外部存储器的 stall 比例降低；
3. 在解码场景中，可观测到可用外部存储空间向键值缓存重分配；
4. 在分布式训练场景中，目标层对应的 All-Reduce 或等效同步数据包体积显著低于稠密基线，甚至呈现缺失。

上述特征可通过 Nsight、Ascend profiler、硬件计数器、网络抓包或等效性能分析工具观测。

## 十二、与现有技术的区别

### 1. 与一般 Hypernetwork 的区别

本发明不是单纯地主张“由一个网络生成另一个网络的权重”，而是强调：

1. 运行时条件生成；
2. 生成的是临时权重描述子块而非外存持久保存的完整权重；
3. 生成后仅在片上局部存储器中存在；
4. 使用后立即释放；
5. 全生命周期不回写外部存储器；
6. 可扩展到训练反向和通信门控。

### 2. 与 LoRA/静态低秩压缩的区别

LoRA 与静态低秩方案的低秩因子通常为持久参数，而本发明中的低秩因子块优选为运行时生成、临时存在、用后销毁。

### 3. 与 IO-aware kernel 的区别

现有 IO-aware kernel 主要减少激活或注意力中间结果的外存访问，本发明进一步把优化对象前移到了“权重本身的创建和生命周期”。

### 4. 与传统训练通信优化的区别

现有训练系统多强调梯度压缩或优化器分片，而本发明进一步限定与临时权重描述子块对应的局部梯度块本身不进入优化器状态缓存，也不同步大块梯度。

## 十三、希望重点保护的技术点

### 第一层保护重点：前向核心防御

1. 运行时根据条件信号生成临时权重描述子块；
2. 在片上局部存储器中转换为临时目标权重分块或者等效因子分块；
3. 当前块计算完成后立即释放、覆写或清零；
4. 在全生命周期内不将对应目标权重分块的完整物理形态写回外部存储器。

### 第二层保护重点：推理解码防御

1. 自回归解码场景；
2. 将节省的外部存储容量动态重分配给键值缓存；
3. 至少两个缓冲区的双缓冲生成与计算重叠；
4. 超长上下文或高并发推理场景。

### 第三层保护重点：训练与通信防御

1. 反向传播时重新在片上局部存储器中生成对应块；
2. 对应局部梯度块不进入全局优化器状态缓存；
3. 对应局部梯度块豁免参与多节点同步；
4. 仅同步元生成器参数、基库参数或者其他压缩参数子集。

### 4. Descriptor 生命周期验证

**Profiler 证据（NVIDIA Nsight）**：

- 生成器内核在 SM 上执行，输出 `U, V` 因子到寄存器/共享内存

- 未观察到 HBM 存储指令

消费阶段：
- 融合内核从共享内存读取 `U, V`
- 原地计算 `x U` 和 `(x U) V`
- 中间结果保留在寄存器中

释放阶段：
- 共享内存通过 `__syncthreads()` 和 `memset` 显式清零
- 内核完成后无残留数据
- Profiler 确认零 descriptor 回写

**数值正确性**：
- 参考 PyTorch 路径（物化 `U V`）：输出最大误差 = 0
- 融合内核路径：输出最大误差 = 1.2e-4（在 fp16 容差内）
