# 说明书草案

## 一、发明名称

一种面向存储带宽受限神经网络推理的即时临时元权重生成系统及方法

---

## 二、技术领域

本发明涉及人工智能加速推理技术领域，尤其涉及在 GPU、NPU、TPU 及其他 AI 加速器上执行的神经网络推理系统与方法。更具体地，本发明涉及一种在推理时根据至少包括 token 相关特征和层标识的条件信号实时生成线性变换权重描述子 tile、仅在片上存储区域内使用所述权重描述子 tile、并在使用后不回写外部存储而直接释放的执行机制。

---

## 三、背景技术

### 1. 大模型推理中的存储带宽瓶颈

现代大模型推理的性能瓶颈通常并非来自纯算力不足，而是来自大规模权重从外部存储向片上计算资源的重复搬运。在 Transformer 架构中，前馈网络块中的上投影、门控投影和下投影矩阵通常占据大量参数量，其从高带宽显存、片外 DRAM 或主机内存向片上资源的搬移会显著影响 token 时延。

随着矩阵计算单元吞吐持续提升，而可持续外部存储带宽提升相对有限，计算单元常常因等待权重数据而空转，这一现象通常被称为“memory wall”。

### 2. 现有方案的局限性

现有技术未能从根本上解决上述外部存储搬运问题：

1. **量化技术** 虽可减少每个存储权重的字节数，但仍需从外部存储读取相应权重；
2. **静态低秩压缩** 虽可存储更小的因子矩阵，但这些因子仍为持久参数，推理时仍需取数；
3. **混合专家模型（MoE）** 虽减少激活计算，但被选中的专家权重仍需装载；
4. **内核融合技术** 主要减少激活中间结果搬运，而非消除投影权重本身的取数；
5. **超网络或参数生成网络** 虽可能涉及参数生成，但通常并未限定一种在片上 tile 级生成、消费、释放且禁止外存回写的推理执行生命周期。

因此，仍有必要提出一种面向加速器硬件内存层级的技术方案，用于在推理过程中减少线性投影权重的外部存储搬运。

---

## 四、发明内容

### （一）发明目的

本发明的目的在于提供一种神经网络推理系统及方法，通过将部分线性投影的静态稠密权重替换为按需生成的临时权重描述子 tile，并在片上存储区域内完成生成、计算和释放，从而降低外部存储流量，提高矩阵计算单元利用率，并改善带宽受限硬件上的推理性能。

### （二）技术方案

为实现上述目的，本发明采用如下技术方案：

一种神经网络推理系统，包括：

1. 一加速器，所述加速器包括矩阵计算单元、片上存储区域以及外部存储区域；
2. 一条件模块，用于获取当前推理步骤的条件信号，所述条件信号至少包括 token 相关特征表示和层标识；
3. 一元生成器，用于根据所述条件信号生成目标神经网络层至少一个线性变换的权重描述子 tile；
4. 一融合执行引擎，用于将所述权重描述子 tile 放置于片上存储区域中，并通过包括 `Y = (XU)V` 的基于结合律的矩阵分解执行线性变换，在输出累积完成前保持所述权重描述子 tile 位于片上存储中，并在生成下一个 tile 之前释放或覆写当前 tile；以及
5. 一存储生命周期控制器，用于在推理过程中阻止所述权重描述子 tile 回写至外部存储区域。

进一步地，本发明还提供一种神经网络推理方法，包括：

1. 接收当前推理步骤的激活张量；
2. 由所述激活张量形成 token 特征表示，并结合层标识得到条件信号；
3. 由元生成器生成至少一个投影对应的权重描述子 tile；
4. 将所述权重描述子 tile 仅存放于片上存储中，并通过基于结合律的矩阵分解执行部分输出计算；
5. 对部分输出进行累积得到输出张量；以及
6. 在生成下一权重描述子 tile 前，对当前权重描述子 tile 进行释放、覆写或清零，且不将其作为持久模型权重写入外部存储。

### （三）有益效果

与现有技术相比，本发明至少具有以下有益效果：

1. 减少针对目标投影的外部存储读写流量；
2. 将部分推理路径由“取权重受限”转为“计算受限”；
3. 提高矩阵计算单元利用率，降低因等待权重搬运产生的空转；
4. 降低目标层的模型驻留存储需求；
5. 支持与静态权重共存的混合执行方式；
6. 支持从预训练稠密模型迁移至本发明方案。

### （四）发明核心边界

本发明的核心不在于单纯的低秩分解，也不在于抽象意义上的参数生成，而在于以下面向硬件内存层级的执行闭环：

`条件输入 -> 生成 descriptor tile -> 存入片上存储 -> 基于结合律的计算 -> 释放且不回写外部存储`

## 六、具体实施方式

以下结合具体实施方式对本发明作进一步说明，但本发明并不限于以下实施方式。

### 实施方式一：术语界定

在本说明书中：

1. **片上存储区域** 包括寄存器、共享内存、SRAM、缓存或其组合；
2. **外部存储区域** 包括高带宽显存、片外 DRAM、主机内存、持久存储或其组合；
3. **权重描述子 tile** 指低秩因子 tile、用于重构低秩因子的基系数 tile，或其组合；
4. **禁止回写** 指在所述推理执行路径中，不将生成的权重描述子 tile 作为持久模型权重写入外部存储区域。

### 实施方式二：系统总体结构

如图2所示，本发明系统可包括：

1. 激活输入路径；
2. 条件模块；
3. 层标识输入模块；
4. 元生成器；
5. 片上存储区域；
6. 融合执行引擎；
7. 存储生命周期控制器；
8. 与外部存储区域耦合的矩阵计算单元。

其中，条件模块接收至少 token 相关特征表示和层标识。在可选实施方式中，条件模块还可接收序列位置信息、路由摘要、领域标识、任务标识、批统计量或硬件执行配置文件。

元生成器可在多个 Transformer 层之间共享，并利用层嵌入区分不同层输出。

### 实施方式三：推理执行流程

在一个实施方式中，推理过程包括：

1. 接收当前推理步骤的激活张量；
2. 根据激活张量形成 token 特征表示，并结合层标识生成条件信号；
3. 由元生成器根据条件信号生成至少一个目标投影对应的权重描述子 tile；
4. 将所述权重描述子 tile 仅存储于片上存储区域，并利用基于结合律的矩阵分解执行部分输出计算；
5. 对部分输出进行累积，得到投影输出；
6. 在生成下一个 tile 之前，释放或覆写当前 tile，且不将其写入外部存储区域。

上述过程可由单个融合内核 执行，也可由保持同等存储生命周期约束的紧耦合执行路径实现。

### 实施方式四：基于结合律的矩阵乘积执行

对于目标线性变换，其传统形式可表示为稠密矩阵 `W` 与输入 `X` 的乘积。本发明不要求在推理时将对应稠密矩阵 `W` 作为外部存储中的完整操作数存在，而是通过生成的低秩因子 tile 执行基于结合律的分解：

`W_eff ~= U V`

并计算：

`Y = (XU)V`

因此，与所述权重描述子对应的完整稠密矩阵无需在外部存储区域中物化或持久存储。

### 实施方式五：前馈网络块实施例

在优选实施方式中，目标神经网络层为 Transformer 的前馈网络块。可针对该前馈网络块的上投影、门控投影和下投影分别生成对应的权重描述子 tile。

对于门控前馈网络块，可执行：

`A = phi((XU_up)V_up)`

`G = psi((XU_gate)V_gate)`

`Y = ((A .* G)U_down)V_down`

其中，上投影、门控投影和下投影对应的每个权重描述子 tile 均在片上存储中生成并消费，之后释放或覆写。

### 实施方式六：低秩因子与基库重构实施例

在一实施方式中，权重描述子 tile 包括第一低秩因子 tile `U` 和第二低秩因子 tile `V`，其秩 `r` 满足 `r < min(d_in, d_out)`。

在另一实施方式中，元生成器输出基库系数，由融合执行引擎在片上存储区域中根据基库系数重构低秩因子，然后立即用于后续计算，计算后释放或覆写，而不回写外部存储。

### 实施方式七：tile 级存储生命周期

融合执行引擎优选以 tile 为单位工作。对于每一个 tile，执行：

1. 提供激活 tile；
2. 根据条件信号生成对应权重描述子 tile；
3. 将生成的权重描述子 tile 放置于片上存储区域；
4. 由矩阵计算单元消费所述权重描述子 tile 以生成部分输出；
5. 对部分输出进行累积；
6. 在生成下一个权重描述子 tile 前，由存储生命周期控制器对当前 tile 执行释放、覆写或清零。

在优选实施方式中，上述流程在单次持久化内核 启动中完成。

### 实施方式八：自适应秩与混合调度

在一些实施方式中，低秩秩值 `r` 可根据 token 复杂度、层深度、时延目标、可用带宽或矩阵计算单元占用率进行自适应调整。

在混合实施方式中，调度器可按层、按 token 或按批次 在生成权重描述子路径与静态存储权重路径之间切换。例如，仅对部分前馈网络层启用本发明，而其他层保留静态稠密权重。

### 实施方式九：分组 token 复用

在某些实施方式中，可将具有相似条件信号的多个 token 分组，并在有界时间窗口内复用至少部分生成的权重描述子。但即便在此情况下，被复用的权重描述子仍保持非持久形式，不作为模型权重写入外部存储区域。

### 实施方式十：从预训练稠密模型迁移

在一个实施方式中，可从预训练稠密模型初始化，并将至少一个存储的稠密投影替换为元生成器和融合执行引擎。随后冻结原模型参数的部分子集，并通过持续训练或知识蒸馏优化剩余参数。

可选损失函数包括：

1. token 级交叉熵；
2. 隐藏状态匹配；
3. 注意力图匹配；
4. 相对于教师模型的 KL 散度；
5. 带宽感知正则项。

### 实施方式十一：硬件实现形式

融合执行引擎可由以下任一种形式实现：

1. Triton 内核；
2. CUDA 内核；
3. ROCm 或 HIP 内核；
4. NPU 微代码路径；
5. TPU 自定义调用；
6. 其他能够提供矩阵计算单元、片上存储和生命周期控制的加速器执行路径。

在优选实施方式中，元生成器与融合执行引擎充分耦合，使得生成的权重描述子 tile 仅在片上存储区域内创建、消费和释放，而不在外部存储区域中存储对应完整稠密矩阵。

### 实施方式十二：与现有技术的区别

本发明至少具有如下区别：

1. 相对于量化技术，本发明改变了推理时投影操作数的生成与使用方式，而非仅减少存储权重的位宽；
2. 相对于静态低秩压缩，本发明中的权重描述子受运行时条件信号控制，并且是非持久的；
3. 相对于一般超网络，本发明限定了硬件内存层级以及“生成-消费-释放且不回写”的执行生命周期；
4. 相对于普通 内核融合技术，本发明将融合边界扩展至权重描述子的创建与生命周期管理。

### 实施方式十三：数学表达示例

设 `x_t in R^(1 x d)` 为 token 隐状态，`e_l` 为层表示，则可形成条件向量：

`c_(t,l) = C(x_t, e_l)`

元生成器输出：

`(U_up, V_up, U_gate, V_gate, U_down, V_down) = G_theta(c_(t,l))`

并可计算：

`A = phi((x_t U_up)V_up)`

`G = psi((x_t U_gate)V_gate)`

`y_t = ((A .* G)U_down)V_down`

上述因子在执行期间以 tile 形式存在，并在片上存储区域中完成消费后释放。
