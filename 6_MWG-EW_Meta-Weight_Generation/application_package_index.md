## Recommended Use

1. Send the `Core CN Set` plus the `Attorney Support Set` to outside counsel.
2. Use `counsel_cover_note_CN.md` as the top-level cover memo.
3. Use `agent_email_draft_CN.md` directly as the sending email template.
4. Use `minimal_pending_info_CN.md` first to fill the remaining real-world information with the smallest possible review surface.
5. Use `filing_readiness_checklist_CN.md` to confirm inventor, disclosure, evidence, and filing-path details before sending.
6. Treat the `Legacy / Working Drafts` as internal drafting history only; they intentionally preserve earlier titles, claim scope, and figure plans and should not be sent externally as the current filing set.
7. Use the engineering evidence set to request profiler, HBM, correctness, and recovery data from the R&D team.
8. If prior art gets closer during formal search, update `claims_CN_final.md` first, then sync `patent_spec_CN_final.md`, then `abstract_CN_final.md`.
