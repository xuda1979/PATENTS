# 给专利代理人的邮件草稿

`请协助起草专利申请：面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法`

---

邮件正文建议：

您好，

现将一项拟申请专利的技术材料发您，请协助进行正式专利申请文本整理，并优先按中国发明专利申请口径处理。

本案的核心并不是宽泛意义上的“动态生成权重”，而是以下统一执行闭环：

`运行时条件生成 -> 临时权重描述子分块 -> 片上转换并消费 -> 用后释放 -> 全生命周期不回写外部存储器 -> 可选反向重算 -> 可选通信豁免`

我们希望重点保护的技术边界包括：

1. 加速器明确区分片上存储器和外部存储器；
2. 条件信号至少包括激活特征表示和层标识；
3. 元生成器在执行时生成临时权重描述子块；
4. 临时对象仅在片上存储器中转换、驻留并被消费；
5. 使用后释放、覆写或清零；
6. 在全生命周期内不将对应完整稠密矩阵物化或回写于外部存储器；
7. 同一申请中同时覆盖推理解码场景和训练反向/通信场景。

本次随附文件包括：

1. 主案权利要求：`claims_CN_final.md`

3. 摘要：`abstract_CN_final.md`
4. 正式交底书：`一种面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法-交底书.md`
5. 检索报告：`一种面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法-检索报告.md`
6. 权利要求支撑表：`claim_support_map_CN_final.md`

10. 最小待补信息清单：`minimal_pending_info_CN.md`
11. 当前申请包索引：`application_package_index.md`

请重点关注以下事项：

1. 维持说明书和权利要求术语一致，尤其是“片上存储器”“外部存储器”“临时权重描述子块”“不回写”等术语；
2. 主案优先保留当前覆盖范围；
3. 若正式检索出现更近文献，请结合备用案收窄；
4. 如有必要，可建议中国申请、PCT 或美国并行布局策略。

目前仍待我们补充的信息已压缩整理为最小清单，主要包括：

1. 申请主体信息；
2. 是否已有对外公开；
3. 最早完成时间；
4. 是否已有 profiler 和实验数据可作为技术效果支撑；
5. 正式附图。

如需快速核对，请优先参考：
