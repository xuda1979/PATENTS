# 中文摘要

## 一种面向存储带宽受限神经网络推理的即时临时元权重生成系统及方法

本发明公开了一种神经网络推理系统及方法，用于降低 Transformer 等神经网络在推理过程中的外部存储带宽压力。所述系统包括加速器、条件模块、元生成器、融合执行引擎和存储生命周期控制器。加速器包括矩阵计算单元、片上存储区域和外部存储区域。条件模块根据至少包括 token 相关特征表示和层标识的条件信号驱动元生成器生成权重描述子 tile。融合执行引擎将所述权重描述子 tile 存入片上存储区域，并通过包括 `Y=(XU)V` 的基于结合律的矩阵分解执行线性变换，在输出累积完成后于生成下一 tile 之前对当前 tile 进行释放或覆写。所述权重描述子 tile 在推理过程中不作为完整稠密权重矩阵存储于外部存储区域，也不回写为持久模型权重。本发明可降低目标投影的外部存储流量，提高矩阵计算单元利用率，并支持从预训练稠密模型迁移至该执行路径。
