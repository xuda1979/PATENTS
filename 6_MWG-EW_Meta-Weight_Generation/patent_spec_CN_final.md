# 说明书定稿建议
# 一种面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法

---

## 一、发明名称

一种面向存储带宽受限神经网络执行的临时权重描述子生成、消费与生命周期控制系统及方法

---

## 二、技术领域

本发明涉及人工智能推理、神经网络训练、分布式训练通信优化和加速器体系结构技术领域，尤其涉及一种在 GPU、NPU、TPU 及其他 AI 加速器上执行的神经网络执行系统及方法。更具体地，涉及一种在前向执行或反向传播过程中根据条件信号实时生成临时权重描述子块，在片上局部存储器中完成生成后消费，并在全生命周期内阻止其完整物理形态写回外部存储器的执行机制。

---

## 三、背景技术

随着大语言模型及其他 Transformer 模型规模持续增大，前向推理和训练反向传播的性能瓶颈越来越多地来源于参数搬运、优化器状态访问以及节点间同步通信，而非矩阵计算本身。尤其在前馈网络块中，上投影、门控投影和下投影矩阵通常参数量巨大，在推理时需要被反复读取，在训练时还需要参与梯度计算、优化器状态更新以及多节点同步。

当这些矩阵以静态稠密权重形式保存在高带宽显存、片外 DRAM 或主机内存中时，系统需要不断将大规模权重从外部存储器搬运到片上资源。与此同时，在分布式训练场景中，局部梯度和优化器状态还会占用额外外部存储空间，并通过 NVLink、InfiniBand、RoCE 或其他节点间高带宽通信总线参与 All-Reduce 或等效同步操作，进一步放大带宽压力。

现有技术中，量化、静态低秩压缩、LoRA、Mixture-of-Experts、Hypernetwork 以及 IO-aware kernel 等方案分别从位宽压缩、静态参数裁剪、稀疏激活、动态生成或中间结果访存优化等角度进行改进，但通常仍默认目标权重以持久形式存在于外部存储器中，未将以下组合特征作为统一的系统执行闭环进行约束：

`条件输入 -> 片上生成临时权重描述子块 -> 片上消费 -> 用后释放 -> 全生命周期不回写外部存储器 -> 可选反向重算 -> 可选通信豁免`

因此，仍有必要提出一种面向加速器物理内存层级和分布式通信路径的执行方案，使目标权重分块在前向和反向阶段均可以临时生成、片上消费并即时销毁，从而同时降低外部存储流量和训练通信流量。

## 四、发明内容

### （一）发明目的

本发明的目的在于提供一种神经网络执行系统及方法，在不依赖外部存储器反复读取完整稠密投影矩阵的情况下，完成目标神经网络层的前向线性变换和反向梯度计算，从而降低外部存储流量，提高矩阵计算单元利用率，并在训练场景中减少优化器状态访问和跨节点同步负担。

### （二）技术方案

为实现上述目的，本发明提供如下技术方案。

一种神经网络执行系统，包括：

1. 一加速器，所述加速器包括第一算术逻辑单元、第二算术逻辑单元、片上局部存储器以及外部存储器；
2. 一条件模块，用于在当前前向执行步骤或者反向传播步骤中获取条件信号，所述条件信号至少包括当前激活块对应的特征表示以及目标神经网络层的层标识；
3. 一元生成器，用于根据所述条件信号生成至少一个线性变换对应的临时权重描述子块；
4. 一融合执行引擎，用于在所述片上局部存储器中将所述临时权重描述子块转换为临时目标权重分块或者等效因子分块，并驱动所述第二算术逻辑单元完成当前输出块或者当前梯度块的计算；
5. 一存储生命周期控制器，用于在当前块计算完成后释放、覆写或者清零当前临时权重描述子块以及对应的临时目标权重分块，并在对应片上缓冲区被重用前完成所述释放、覆写或者清零，且在其全生命周期内阻止其完整物理形态写回所述外部存储器；
6. 可选地，一反向重算模块，用于在反向传播时再次在所述片上局部存储器中生成对应的临时权重描述子块，并完成局部梯度块计算；
7. 可选地，一优化器与通信门控控制器，用于阻止与所述临时权重描述子块对应的局部梯度块进入全局优化器状态缓存，并使所述局部梯度块豁免参与多个计算节点之间的梯度同步。

进一步地，本发明还提供一种神经网络执行方法，包括：

1. 接收当前前向执行步骤或者反向传播步骤中的激活块、中间状态块或者梯度信号；
2. 结合层标识形成条件信号；
3. 由元生成器生成当前线性变换对应的临时权重描述子块；
4. 仅将所述临时权重描述子块写入片上局部存储器，并在所述片上局部存储器中将其转换为临时目标权重分块或者等效因子分块；
5. 驱动矩阵计算单元完成当前输出块或者当前梯度块的计算；
6. 在当前块计算完成后释放、覆写或者清零当前临时权重描述子块以及对应的临时目标权重分块，并在对应片上缓冲区被重用前完成所述释放、覆写或者清零；
7. 在所述当前临时权重描述子块及其对应的临时目标权重分块的全生命周期内，阻止将其完整物理形态写回外部存储器。

### （三）有益效果

与现有技术相比，本发明至少具有以下有益效果：

1. 减少目标投影在推理和训练过程中的外部存储器读写流量；
2. 避免与所述临时权重描述子块对应的完整稠密权重矩阵在执行期间于外部存储器中实体化；
3. 提高矩阵计算单元利用率，使部分路径由带宽受限转化为片上计算受限；
4. 在自回归解码场景中可将节省的外部存储空间动态分配给键值缓存；
5. 在训练场景中可通过反向重算减少静态权重读取，并通过优化器与通信门控降低优化器状态访问和跨节点同步负担；
6. 该技术效果可通过标准 profiler、内存计数器和网络抓包工具在外部进行物理观测。

### （四）发明核心边界

本发明的核心不在于单纯的低秩分解本身，也不在于宽泛意义上的“动态生成权重”，而在于以下面向加速器内存层级和训练通信路径的执行闭环：

`条件输入 -> 生成临时权重描述子块 -> 片上转换为临时目标权重分块 -> 片上消费并累积结果 -> 释放/覆写 -> 不回写外部存储器 -> 可选反向重算 -> 可选通信豁免`

## 六、具体实施方式

以下结合具体实施方式对本发明作进一步说明，但本发明并不限于以下实施方式。

### （一）术语定义

为便于理解本发明，作如下定义：

1. **片上局部存储器** 包括寄存器、共享内存、SRAM、缓存或者其组合；
2. **外部存储器** 包括高带宽显存、片外 DRAM、主机内存、持久存储或者其组合；
3. **临时权重描述子块** 指低秩因子块、用于重构低秩因子的基系数块、用于形成目标权重分块的控制参数块或者其组合；
4. **临时目标权重分块** 指根据所述临时权重描述子块在片上局部存储器中形成并立即用于当前块计算的权重分块；
5. **第一算术逻辑单元** 指配置为执行标量、向量、非线性变换、系数重构或地址控制的处理单元；
6. **第二算术逻辑单元** 指配置为执行高密度矩阵乘加、张量乘加或等效乘累加的处理单元；
7. **节点间高带宽通信总线** 包括 NVLink、HCCS、InfiniBand、RoCE 或其他用于多节点同步的互连；
8. **不回写** 指在所述临时权重描述子块及其对应的临时目标权重分块的全生命周期内，不将其完整物理形态写入外部存储器作为持久模型权重、优化器状态或者训练同步对象。

### （二）平台无关映射实施方式

本发明的核心保护边界采用平台无关术语进行描述。不同硬件平台可按如下方式映射，但该映射仅作为实施例，不构成限制：

| 平台相关对象 | 本发明术语 |
| --- | --- |
| HBM、片外显存、主板 DDR | 外部存储器 |
| UB、L0A、L0B、shared memory、L1 SRAM | 片上局部存储器 |
| Vector Core、CUDA Core、SIMD 核 | 第一算术逻辑单元 |
| Tensor Core、Cube、脉动阵列 | 第二算术逻辑单元 |
| HCCS、NVLink、InfiniBand、RoCE | 节点间高带宽通信总线 |

因此，在具体实施例中可以采用 Ascend、NVIDIA、AMD、TPU 或其他加速器实现本发明，而不改变本发明的技术实质。

### （三）系统结构实施方式

结合图2所示主链路以及本发明各实施方式，系统可包括：

1. 激活输入路径；
2. 条件模块；
3. 层标识输入模块；
4. 元生成器；
5. 片上局部存储器；
6. 融合执行引擎；
7. 存储生命周期控制器；
8. 反向重算模块；
9. 优化器与通信门控控制器；
10. 解码缓存分配器；
11. 调度器；
12. 监测模块；
13. 与外部存储器和节点间高带宽通信总线耦合的算术逻辑单元。

条件模块接收至少当前激活块特征表示和层标识。可选地，条件模块还可接收序列位置嵌入、路由摘要、领域标识、任务标识、批统计量、序列长度信息或者硬件执行配置文件。

元生成器可在多个 Transformer 层之间共享，并通过层嵌入区分不同层的生成输出。

### （四）前向执行实施方式

在一个实施方式中，前向执行过程包括：

1. 从外部存储器读取当前层指令、激活块地址和层标识；
2. 在片上局部存储器中形成条件信号；
3. 由元生成器生成当前线性变换对应的临时权重描述子块；
4. 由第一算术逻辑单元在片上局部存储器中将所述临时权重描述子块转换为临时目标权重分块或者等效因子分块；
5. 由第二算术逻辑单元消费所述临时目标权重分块或者等效因子分块并生成当前输出块；
6. 对当前输出块进行累积；
7. 在当前块计算完成后释放、覆写或清零当前临时权重描述子块以及对应的临时目标权重分块，并在对应片上缓冲区被重用前完成所述释放、覆写或清零；
8. 在整个过程中不将所述当前临时权重描述子块或当前临时目标权重分块的完整物理形态写回外部存储器。

上述过程可以由单个融合 kernel 执行，也可以由保持同等生命周期约束的紧耦合执行路径实现。

### （五）解码推理与键值缓存实施方式

在自回归解码实施方式中，本发明通过避免将大规模静态权重反复写入和读出外部存储器，释放出更多外部存储容量。所述容量可由解码缓存分配器重定向给键值缓存、超长上下文缓存或其他解码状态缓存。

在优选实施方式中，片上局部存储器包括两个或多个交替使用的缓冲区。当第二算术逻辑单元消费当前临时权重描述子块时，元生成器和第一算术逻辑单元同时在另一缓冲区内生成下一临时权重描述子块，从而实现生成路径与矩阵乘加路径的时间重叠。

### （六）结合式矩阵执行实施方式

对于目标线性变换，其传统形式通常可表示为输入 `X` 与稠密矩阵 `W` 的乘积。本发明并不要求在执行时将稠密矩阵 `W` 作为完整操作数从外部存储器读入，而是允许临时权重描述子块在片上局部存储器中形成等效因子分块，例如：

`W_eff ~= UV`

并在实施例中采用：

`Y = (XU)V`

上述公式仅用于说明一种可选的片上执行方式。本发明的保护重点在于所述权重对象的物理驻留位置、生成后消费的控制流程和用后销毁的生命周期限制，而非公式本身。

### （七）Transformer 前馈网络实施方式

在优选实施方式中，目标神经网络层为 Transformer 的前馈网络块。可针对该前馈网络块的上投影、门控投影和下投影分别生成临时权重描述子块。

对于门控前馈网络块，可执行如下等效前向计算：

`A = phi((XU_up)V_up)`

`G = psi((XU_gate)V_gate)`

`Y = ((A .* G)U_down)V_down`

其中，各投影对应的临时权重描述子块均在片上局部存储器中生成并消费，之后释放、覆写或清零。

### （八）基库重构与自适应秩实施方式

在一实施方式中，临时权重描述子块包括第一低秩因子块和第二低秩因子块，其秩值小于目标投影的输入维度和输出维度中的较小者。

在另一实施方式中，元生成器输出学习基库的系数，融合执行引擎在片上局部存储器中根据所述系数重构低秩因子块，重构后立即用于计算，并在计算后释放且不回写外部存储器。

在一些实施方式中，秩值或者块大小可根据 token 复杂度、层深度、时延目标、可用带宽、片上局部存储容量或者矩阵计算单元占用率自适应调整。

在混合实施方式中，调度器可按层、按 token、按 batch 或按训练阶段在动态生成权重路径与静态存储权重路径之间切换。

在某些实施方式中，可将具有相似条件信号的多个 token 分组，并在有界时间窗口内复用至少部分临时权重描述子块，但保持所述临时权重描述子块为非持久形式且不回写外部存储器。

### （九）分块生命周期实施方式

融合执行引擎优选以块为粒度执行。对于每一个临时权重描述子块，执行：

1. 提供相应激活块、中间状态块或者梯度信号；
2. 根据条件信号生成对应临时权重描述子块；
3. 将该临时权重描述子块写入片上局部存储器；
4. 在片上局部存储器中转换为临时目标权重分块或者等效因子分块；
5. 由第二算术逻辑单元消费所述临时目标权重分块或者等效因子分块并生成当前输出块或者当前梯度块；
6. 累积当前输出块或者当前梯度块；
7. 在当前块计算完成后释放、覆写或清零当前临时权重描述子块以及对应的临时目标权重分块，并在对应片上缓冲区被重用前完成所述释放、覆写或清零。

在优选实施方式中，以上流程在单次持久化 kernel 启动中完成。

### （十）反向训练重算实施方式

在训练实施方式中，系统在反向传播阶段不从外部存储器中直接读取完整稠密权重矩阵作为梯度计算操作数，而是由反向重算模块在收到权重读取请求后，再次在片上局部存储器中生成与当前反向块对应的临时权重描述子块，并由第一算术逻辑单元将其转换为当前反向所需的临时目标权重分块或者等效因子分块。

随后，第二算术逻辑单元使用所述临时目标权重分块或者等效因子分块完成局部梯度块、输入梯度块或参数梯度块的计算；在当前反向块计算结束后，立即释放、覆写或清零当前临时权重描述子块以及对应的临时目标权重分块，而不在外部存储器中形成完整稠密矩阵。

### （十一）优化器状态与通信门控实施方式

在分布式训练实施方式中，优化器与通信门控控制器可以对与临时权重描述子块对应的局部梯度块实施以下至少之一：

1. 阻止其进入 Adam、AdamW 或其他全局优化器的状态缓存；
2. 阻止其作为独立大矩阵梯度参与 All-Reduce、Reduce-Scatter 或等效同步；
3. 仅对元生成器参数、基库参数或者其他压缩参数子集执行跨节点同步。

通过上述方式，可使目标层在网络抓包或通信计数器中表现为同步数据量显著低于稠密基线。

### （十二）迁移训练实施方式

在一个实施方式中，可从预训练稠密模型初始化，并将至少一个存储的稠密投影替换为元生成器和融合执行引擎。随后冻结原模型参数的部分子集，并通过继续训练或知识蒸馏优化剩余参数。

可选损失函数包括：

1. token 级交叉熵；
2. 隐藏状态匹配；
3. 注意力图匹配；
4. 相对于教师模型的 KL 散度；
5. 带宽感知正则项；
6. 通信感知正则项。

### （十三）可观测特征实施方式

如图7所示，当本发明的执行路径生效时，可通过标准 profiler、硬件性能计数器或网络抓包工具观测到以下至少之一物理特征：

1. 在执行目标层时，外部存储器读写字节数显著低于按完整稠密权重矩阵访问所对应的理论下限；
2. 矩阵计算单元利用率保持在高水平，而等待外部存储器的 stall 比例降低；
3. 在自回归解码场景中，可观测到可用外部存储容量向键值缓存重分配；
4. 在分布式训练场景中，目标层对应的 All-Reduce 或等效同步数据包体积显著低于稠密基线，甚至呈现缺失。

其中，所述理论下限是指在给定目标层、给定分块或给定执行步骤中，至少一次从外部存储器读取对应完整稠密权重矩阵所需的字节量。所述可观测特征可用于验证本发明是否在外部物理层面实现了预期的数据流。

### （十四）硬件实现形式

融合执行引擎可由以下任一种形式实现：

1. Triton kernel；
2. CUDA kernel；
3. ROCm 或 HIP kernel；
4. NPU 微代码路径；
5. TPU 自定义调用；
6. 其他能够提供第一算术逻辑单元、第二算术逻辑单元、片上局部存储器和生命周期控制的加速器执行路径。

在优选实施方式中，元生成器与融合执行引擎充分耦合，使得生成的临时权重描述子块仅在片上局部存储器中创建、消费和释放，而不在外部存储器中形成对应完整稠密矩阵。

### （十五）与现有技术的区别

本发明至少具有如下区别：

1. 相对于量化和静态低秩压缩，本发明改变了前向和反向过程中目标权重的生成、消费和销毁方式，而非仅减小静态参数规模；
2. 相对于一般 Hypernetwork，本发明强调片上局部存储器中的分块生成-消费-释放生命周期；
3. 相对于 IO-aware kernel，本发明将内存层级优化对象从激活中间结果进一步扩展到权重对象本身；
4. 相对于片上常驻静态权重方案，本发明强调运行时即时生成和即时释放；
5. 相对于传统分布式训练，本发明进一步约束局部梯度和优化器状态的去向，从而降低跨节点同步和优化器状态缓存压力。

### （十六）总结

本发明的核心创新点在于，将目标权重对象由“外部存储器中的静态持久权重”转为“片上局部存储器中的运行时临时权重描述子块和临时目标权重分块”，并将其绑定到统一的生成、消费、释放和不回写生命周期约束中。通过这一设计，本发明能够同时改善推理、解码和训练场景中的外部存储与通信压力，并提供可由外部工具验证的物理可观测特征。
